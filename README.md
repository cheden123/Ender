# Ender Watch

Android-приложение и домашний сервер для одного принтера с Klipper и Moonraker. На телефоне видны камера, файл, прогресс, расчётное оставшееся время, температура сопла и стола. С телефона можно загрузить G-code, запустить задание, приостановить, продолжить или отменить печать. В истории сохраняются снимки и таймлапсы MP4.

Сервер проверяет кадры локальной моделью MobileViT. После трёх подозрительных кадров подряд во время печати он сохраняет снимок события. Android показывает уведомление и открывает снимок. Пользователь подтверждает паузу вручную. Команда содержит идентификатор задания, поэтому опоздавшее уведомление не должно приостанавливать следующую печать.

## Установка сервера на Proxmox

1. Подготовьте Linux-ВМ с Docker Engine и плагином Docker Compose v2. ВМ должна видеть Raspberry Pi, а телефон — ВМ по Wi-Fi и через ваш VPN. ВМ будет хранить SQLite, JPEG и MP4 на своём диске. Raspberry Pi продолжает работать с Klipper, Moonraker и существующей камерой.
2. Распакуйте комплект сервера в отдельную папку. Из неё выполните:

   ```sh
   cp .env.example .env
   chmod 600 .env
   openssl rand -hex 32
   ```

3. Откройте `.env` в текстовом редакторе и заполните значения из таблицы. Примеры адресов замените своими.

   | Параметр | Что указать |
   |---|---|
   | `BIND_ADDRESS` | LAN-адрес самой Linux-ВМ, например `192.168.1.50`. |
   | `PORT` | Порт приложения, по умолчанию `8080`. |
   | `APP_TOKEN` | Сгенерированную строку из команды выше. Тот же токен понадобится на Android. |
   | `MOONRAKER_URL` | Адрес Moonraker на Pi, например `http://192.168.1.60:7125`. |
   | `MOONRAKER_API_KEY` | Ключ Moonraker, если он требует авторизации для ВМ. Хранится на сервере. |
   | `CAMERA_SNAPSHOT_URL` | Полный URL **одного JPEG** из настроек камеры Mainsail или Fluidd. К относительному пути добавьте адрес Pi и порт веб-интерфейса. Откройте URL с ВМ и проверьте картинку. |
   | `CAMERA_STREAM_URL` | Полный URL MJPEG, если камера предоставляет такой поток. При пустом значении прямой эфир собирается из последовательных JPEG. |
   | `DETECTION_THRESHOLD` | Порог подозрения от 0 до 1, исходное значение `0.50`. Более высокий порог уменьшает чувствительность. |

4. Запустите сервер:

   ```sh
   docker compose up -d --build
   docker compose ps
   docker compose logs --tail=40
   ```

   Первая сборка требует интернета для загрузки Python, FFmpeg, зависимостей и весов модели. Docker проверяет модель по зафиксированному SHA-256. После сборки анализ изображений и уведомления через VPN работают внутри вашей сети. При изменении `.env` примените настройки командой `docker compose up -d`. История находится в именованном томе `print-data`. Команда `docker compose down` сохраняет этот том.

## Подключение Android

1. Установите подписанный `Ender-Watch-0.1.0.apk` на телефон с Android 8 или новее. Если система запросит разрешение на установку из выбранного файлового менеджера, разрешите установку этого APK.
2. На первом экране укажите адрес сервера, например `http://192.168.1.50:8080`, и значение `APP_TOKEN`. Подключитесь к домашнему Wi-Fi. В обзоре должны появиться статус, температуры и кадр с камеры. Откройте «Прямой эфир» и «Файлы» — эти проверки только читают данные.
3. В обзоре включите «Уведомления в фоне». На Android 13 и новее разрешите уведомления. Служба наблюдения поддерживает постоянное системное уведомление и опрашивает сервер. При выключенном VPN вне дома новые события сохраняются на сервере до следующего подключения. После перезагрузки телефона снова включите наблюдение.
4. Проверьте доступ вне дома, отключив Wi-Fi и включив уже настроенный VPN. Используйте тот же адрес ВМ. Для обычного HTTP держите сервер в доверенной LAN/VPN. Для HTTPS можно указать адрес вашего обратного прокси с сертификатом, которому доверяет Android.

## Печать и история

- «Файлы» показывает G-code с принтера. Загрузка файла с телефона и запуск печати — отдельные действия. Перед подтверждением запуска проверьте свободный стол.
- «Обзор» показывает температуры, их график и оценку времени по доле обработанного файла. Оценка меняется по мере печати. Действия над печатью требуют подтверждения. Для паузы и продолжения на Klipper нужен рабочий `[pause_resume]` и соответствующая конфигурация принтера.
- «События» открывает сохранённый снимок обнаружения. Снимок события привязан к заданию. Сервер никогда автоматически не вызывает паузу.
- «История» включает задания, которые сервер наблюдал во время работы. Кадры таймлапса собираются примерно раз в 15 секунд, до 2400 кадров на задание. MP4 появляется после завершения задания и кодирования. Сохраняются до 100 завершённых заданий и до 500 событий. Если ВМ выключена, кадры за это время восстановить нельзя.
- Детектор анализирует центральную часть кадра. Расположите зону печати ближе к центру и обеспечьте стабильное освещение. На независимой фотографии с явным браком модель дала 0,408 при исходном пороге 0,50 и пропустила сбой. Порог подбирают на примерах со своей камеры. [Проверки модели](server/VISION-VERIFICATION.md)

## Если нет данных

| Что видно | Что проверить |
|---|---|
| Телефон не подключается | Адрес и порт ВМ, маршрут VPN, доступ к порту из LAN, совпадение `APP_TOKEN`. |
| Интерфейс подключён, принтер недоступен | Доступ ВМ к `MOONRAKER_URL/printer/info`, адрес/порт Pi, значение `MOONRAKER_API_KEY`, состояние Klipper. |
| Нет изображения | С ВМ откройте точный `CAMERA_SNAPSHOT_URL`. Нужен ответ с изображением. Для прямого эфира проверьте `CAMERA_STREAM_URL` или оставьте пустым. |
| Есть события, но на экране блокировки тихо | Проверьте наблюдение в приложении, разрешение на уведомления, системный канал предупреждений, подключение VPN и ограничения батареи Android. |
| Нет таймлапса | Дождитесь конца задания и кодирования, проверьте наличие кадров и свободное место в томе сервера. |

## Сборка из исходников

Android-проект находится в `android/`. Требуются JDK 17, Android SDK Platform 34 и Build Tools 34.0.0. Для локальной разработки выполните в этой папке `./gradlew :app:assembleDebug` (Windows — `gradlew.bat :app:assembleDebug`). Команда `:app:assembleRelease` создаёт неподписанный APK. Для обновления уже установленного приложения подпишите новую версию тем же закрытым ключом и увеличьте `versionCode`. Закрытый ключ владельца хранится отдельно от публичных исходников.

Запуск серверных проверок из `server/` в Python 3.11:

```sh
python -m pip install -r requirements.in -r requirements-vision.txt pytest
python -m pytest -q
```

CI также собирает образ и проверяет Android-сервер через симулятор Moonraker и камеры. Сведения о весах и лицензиях находятся в [описании модели](server/MODEL-NOTICE.md). Официальные интерфейсы интеграции — [управление печатью Moonraker](https://moonraker.readthedocs.io/en/latest/external_api/printer/) и [файлы Moonraker](https://moonraker.readthedocs.io/en/latest/external_api/file_manager/).
